### Fase 4 — Dangerous Patterns ✓
- Sin `eval()`, `child_process.exec/execSync`, `os.system`, ni `shell: true`.
  (Los `.exec(` detectados son `RegExp.prototype.exec`, no shell.)
- Transport CLI usa `spawn(cmd, argsArray, { shell: false })` con args como lista
  explícita; `schedule.js` usa `spawnSync('launchctl', args, { shell: false })`.
  Nunca se concatena input de usuario en comandos.

  best-effort (liberar socket / abort en backoff) con comentario explícito.

## Notas de diseño relevantes a seguridad
- **Aislamiento de secretos hacia agentes:** el `AgentInput` se construye con
  `stripRaw()` por item — el campo `raw` (que podría traer datos del proveedor)
  nunca llega al agente ni al markdown.
- **Degradación elegante:** una fuente o agente que falla se loguea y registra en
  `run-history.jsonl`; nunca tumba el run ni traga la excepción.
- **Escrituras acotadas:** toda salida queda bajo `docs/news-extractor/` con guard
  anti-traversal y validación de `topic`/`date`.
